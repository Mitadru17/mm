- `node scripts/react-bits-discover.mjs search <query>` searches the entire free TypeScript/CSS catalog. `inspect <exact-identifier>` downloads that candidate's actual source for review.
- The shadcn MCP initialize/tools-list/search sequence succeeded and returned `BlurText-TS-CSS` from `@react-bits`. Records: `docs/react-bits/mcp-tools.json` and `mcp-discovery-result.json`.
- The latest user-wide connection uses the installed shadcn 4.23.0 CLI and a shared registry workspace rather than the hotel cwd. Existing server entries are preserved, with an adjacent config backup. A Codex restart loads the refreshed native tool connection. Protocol initialization, search, source retrieval and an isolated component install/build were verified; see `REACT-BITS-SETUP.md`.
- The CLI is invoked through `npx` rather than retained as an application dependency. The app avoids the CLI's unrelated development dependency tree; production and project audit results are recorded in the delivery report.
